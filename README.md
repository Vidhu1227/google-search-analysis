# Google Search Trend Analysis on Cloud Technologies

Analysis of global Google search interest in "Cloud Computing" using the Google Trends API (Pytrends).

## Tools
Python, Pytrends, Pandas, Matplotlib, Seaborn, Plotly

## What I did
- Built a data analysis pipeline to collect search interest data with Pytrends
- Identified the top 15 countries by interest using bar plots and an interactive Plotly choropleth map
- Ran a time-series analysis of how interest changed over the past 12 months

## Notebook
[google search analysis project (1).ipynb](google%20search%20analysis%20project%20%281%29.ipynb)

## How to run
pip install pytrends pandas matplotlib seaborn plotly

Open the notebook in Jupyter or Google Colab and run all cells.
